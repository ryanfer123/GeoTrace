Evidence you can open

A source behind
every view.

The image is only the beginning. GeoTrace keeps enough context to retrace how it reached your notebook.

  • The exact image request

    Layer, requested date, geographic bounds, and image dimensions stay together. Open the original NASA request from the workspace.

  • A record of the actual file

    Retrieval time and a SHA256 checksum record the source response. Local cached snapshots keep those bytes. Hosted views use NASA image URLs, which may later be reprocessed.

  • Dates checked against the catalog

    Requests are checked against NASA’s advertised availability, including known gaps. A source error remains visible instead of becoming a substitute image.

Before you begin

A few practical
questions.

What can I compare?+

Choose an included geographic area or enter your own bounding box, then request two available dates from one supported NASA layer: MODIS Terra, MODIS Aqua, or VIIRS Suomi NPP true color. Antimeridian-crossing areas are not currently supported.

Do I need an account or API key?+

The included image pair and local analysis work without an account. New areas, dates, and catalog refreshes need a connection to NASA GIBS. Signing in is needed when you choose to save or open private cloud copies. The server supplies its browser-safe cloud configuration; you do not paste API keys into the workspace.

Can this calculate vegetation loss or burn severity?+

No. The app compares browse imagery for visual inspection. It does not compute NDVI, burn severity, water-loss area, or causal attribution. Those questions require suitable scientific data and further analysis.

Where do my investigations go?+

In local mode, investigations and notes use SQLite, with images cached on the same computer. Hosted work is temporary in the browser tab until you export it or save a private copy through Cloud notebook. Cloud copies retain the selected view, notes, and provenance; reopening validates and reloads the sources.

Why is an image blank or cloudy?+

An advertised date does not guarantee clear coverage of every area. Clouds, missing observations, and other source conditions can affect the view. Try another available date and record the limitation in your notes.
